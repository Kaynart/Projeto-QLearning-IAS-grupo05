# Qlearning
Projeto prático de implementação do algoritmo Q-Learning, na área de Inteligência Artificial Simbólica. O sistema consiste em um jogo de caminho em plataformas em busca de alcançar um objetivo, com ações não determinísticas, i.e., em que a ação escolhida não necessariamente implica ação executada. Objetiva-se implementar um algoritmo Q-Learning para obter a tabela de valoração das ações e estados para o problema com a tabela Q.
